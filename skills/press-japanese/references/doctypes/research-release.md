# 研究成果プレスリリース — 論文の主張を超えずに、専門外の記者へ

## この型が答える問い

研究成果のリリースが答える問いは「何が分かったのか。誰にとって何が変わるのか」であり、制約は「論文の主張を一歩も超えない」ことにある。読み手は科学記者と一般の記者で、その分野の専門家ではない。専門用語は機能を説明してから名前を渡し（`natural-japanese` 文体憲法第4条）、結論は「〜の可能性を示した」を「〜を証明した」に格上げしない。ソースは論文（本文・図表・Discussion）と研究者への確認であり、応用の見通しを書けるのは論文か研究者がそう述べているときだけ。

## 必須要素

タイトル（成果を平易に。「〜を発見」「〜を解明」「〜を開発」）、発表のポイント（2〜3点。箇条書き可）、概要（研究者名と所属、成果、掲載誌名と掲載日）、背景、研究内容と手法、成果、今後の展開、用語解説（※1、※2）、論文情報（タイトル・著者・誌名・DOI・公開日）、研究費（助成の名称と番号）、問い合わせ先（研究に関することと報道に関することを分ける）、解禁日時（エンバーゴがあるとき）。

大学・研究機関の多くがこの節立てを標準にしている。節の名前は機関の書式に合わせる。

## 構成の型

概要の一文目は「〇〇大学〇〇研究科の〇〇教授らの研究グループは、〜を明らかにしました。」の形。成果の主語は研究グループ、述語は「明らかにした」「開発した」「示した」など論文の主張の強さに合わせる。発表のポイントは論文の Abstract の主張と一対一で対応させ、Abstract にない主張を足さない。

背景は論文の Introduction にある範囲で、研究内容は Methods を平易に、成果は Results を数値つきで、今後の展開は Discussion の範囲で書く。用語解説は本文で初出に※番号を振り、末尾でまとめる。解説の定義は論文か教科書的な定義に限り、比喩による独自説明はしない。

共同研究の機関名と順序、著者の肩書、誌名の正式表記、DOI は事実表で1つずつ確認する。

## 品質基準

**主張の強さが論文と一致している**。「示唆した」「可能性がある」「関連が見られた」を、「証明した」「解明した」「効果がある」に変えていない。

**数値が論文の値と一致している**。効果量・サンプル数・期間・条件が付いている。`factcheck.py --source 論文.txt` で `unsupported_number` がゼロ。

**応用の見通しが論文の記述の範囲にある**。「〜の治療に道」「〜の実用化が期待される」は、論文の Discussion か研究者の確認がある場合だけ。

**「世界初」に根拠がある**。論文中の記述か、研究者による先行研究の確認があること。

**論文情報が正確**。DOI とタイトルは論文から転記し、機械照合を通している。

## AIがやりがちな失敗

応用の誇張が最も危険で、基礎研究の成果に「〜の治療につながる」「〜の実用化に道」を付け足す。次に、一般向けに平易にする過程で因果を飛躍させる（相関を因果に、細胞実験をヒトの効果に）。用語解説を辞書的に創作する、DOI や誌名を捏造する、共著者の所属を取り違える、も起きる。「世界初」を論文が言っていないのに付ける失敗は、PR TIMESの審査でも最も多い指摘（最上級表現の根拠不足）に直結する。

## 文体憲法の重点条項

- 第4条（機能を説明してから名前）: 専門用語は必ずこの順で。※番号の用語解説と二段構えにする
- 第10条（確信度ラベル）: 論文の「suggest」「may」を落とさない。断定・推定・未確認を語尾でなく表現で書き分ける
- 第11条（事実と意見）: 研究者のコメント枠と、論文の主張を分ける
- 第5条（実数）: 効果量・サンプル数を書く。ただし論文にある値だけ

## 雛形

```
2026年9月15日
〇〇大学

在庫データから欠品の予兆を検出する手法を開発
—小売12店舗の実データで欠品を平均2.3日前に検出—

【発表のポイント】
- 在庫回転率の時系列から欠品の予兆を検出する手法を開発した（F1）
- 小売12店舗、2025年4月〜2026年3月の実データで、欠品を平均2.3日前に検出した（F2）
- 発注の自動化に応用できる可能性がある（F3、論文Discussion）

【概要】
〇〇大学大学院〇〇研究科の〇〇教授、△△准教授らの研究グループは、小売店
の在庫回転率※1の時系列から欠品の予兆を検出する手法を開発しました。…
本成果は2026年9月15日（日本時間）に「〇〇〇〇」誌にオンライン掲載されます。

【背景】…（Introduction の範囲）
【研究内容】…（Methods を平易に）
【成果】…（Results を数値つきで）
【今後の展開】…（Discussion の範囲。【要確認】があれば残す）

【用語解説】
※1 在庫回転率: 一定期間に在庫が何回入れ替わったかを示す指標。売上原価を平均在庫で割って求める。

【論文情報】
タイトル: …（原題のまま） ／ 著者: … ／ 誌名: … ／ DOI: …（論文から転記） ／ 公開日: …

【問い合わせ先】
研究に関すること: 〇〇大学 〇〇研究科 〇〇教授 ／ 報道に関すること: 〇〇大学 広報課
```

## before/after

**Before**

> 〇〇大学は、AIで欠品をなくす画期的な技術を世界で初めて開発し、小売業の人手不足という社会課題の解決に道を開きました。

**After**

> 〇〇大学大学院〇〇研究科の〇〇教授らの研究グループは、小売店の在庫回転率の時系列から欠品の予兆を検出する手法を開発し、12店舗の実データで欠品を平均2.3日前に検出できることを示しました。

「AI」「世界初」「なくす」「社会課題の解決」はいずれも論文の主張にない。Afterは論文の Results の範囲で、数値つきに戻している。
